# NOAH

> **N**ot **O**nly **A**nother **H**ymnal — Fast, resilient, cross-platform worship & lyrics presentation software built with Tauri, Rust, and Svelte.

NOAH is an open-source alternative to SongBeamer designed to run natively on **Windows 11**, **macOS**, and **Linux** (including Raspberry Pi).

## Tech Stack
- **Backend:** Rust / Tauri v2
- **Frontend:** Svelte 5, TypeScript, TailwindCSS
- **Storage:** SQLite & `.sng` file interchange
